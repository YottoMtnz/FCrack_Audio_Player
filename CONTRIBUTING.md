# Contributing / Contribuir

## Español

Este repositorio público está destinado a la **documentación, página oficial y seguimiento de incidencias** de F.Crack Player. El código fuente de la aplicación no se publica aquí.

Son bienvenidos:
- reportes de errores reproducibles;
- sugerencias de experiencia de usuario;
- correcciones de documentación o traducción;
- reportes de enlaces rotos o problemas de la página web.

No envíes música con copyright, archivos privados ni datos personales.

## English

This public repository is intended for **documentation, the official website, and issue tracking** for F.Crack Player. The application's source code is not published here.

Welcome contributions include:
- reproducible bug reports;
- user-experience suggestions;
- documentation or translation corrections;
- reports of broken links or website issues.

Do not submit copyrighted music, private files, or personal information.
