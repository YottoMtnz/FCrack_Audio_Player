# Changelog

## 1.0 — Public release

### Español
- Reproductor local para Windows con interfaz oscura y acentos neón.
- Arrastrar y soltar archivos y carpetas.
- Biblioteca persistente, búsqueda rápida y favoritos.
- Lectura de artista y portada desde metadatos.
- Aleatorio, repetición y nueve perfiles de ecualización.
- Teclas multimedia y control de volumen ampliado.
- Interfaz bilingüe Español / English.
- Personalización de transparencia y colores visuales.
- Instalador con modo completo y modo portable.

### English
- Local Windows audio player with a dark neon-accented interface.
- Drag-and-drop files and folders.
- Persistent library, quick search, and favorites.
- Artist and artwork metadata support.
- Shuffle, repeat, and nine equalizer presets.
- Media keys and extended volume control.
- Bilingual Spanish / English interface.
- Transparency and visual color customization.
- Installer with full and portable modes.
