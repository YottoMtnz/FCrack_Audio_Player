# Security Policy / Política de seguridad

## Español

Si encuentras un problema de seguridad relacionado con F.Crack Player, evita publicar credenciales, datos personales o instrucciones de explotación detalladas en un issue público.

Puedes abrir un issue con una descripción mínima indicando que se trata de un asunto de seguridad para coordinar un canal adecuado de seguimiento.

## English

If you discover a security issue related to F.Crack Player, please avoid posting credentials, personal information, or detailed exploitation instructions in a public issue.

You may open an issue with a minimal description stating that it is a security matter so an appropriate follow-up channel can be coordinated.
