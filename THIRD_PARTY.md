# Third-party components / Componentes de terceros

F.Crack Player uses third-party technologies to provide its desktop interface, audio playback, metadata handling, drag-and-drop, media-key support, image handling, and Windows packaging.

Publicly documented technologies used by the application include:

- Python
- CustomTkinter
- VLC / libVLC and Python VLC bindings
- Mutagen
- Pillow
- pynput
- tkinterdnd2
- PyInstaller

These components remain subject to their respective copyright notices and licenses. The F.Crack Player copyright notice does not claim ownership over third-party software.
